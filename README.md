## Daily Stats - Obsidian Plugin

This is a daily word count and heatmap plugin that is forked from https://github.com/dhruvik7/obsidian-daily-stats. I wanted to update it to modernize the libraries, add new features, and fix bugs I was experiencing. 

### Features

-  Today's word count in the bottom right corner of your screen.
-  A heatmap in the right panel view akin to Github's contribution graph.
- A configurable daily goal to try and encorage writing more.
- The number of words you have written in the last year.
